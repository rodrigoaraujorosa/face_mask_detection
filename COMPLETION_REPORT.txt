================================================================================
                        TECHNICAL SPECIFICATIONS
================================================================================

DATASET
-------
Source: Kaggle (andrewmvd/face-mask-detection)
Download: Automatic via kagglehub API
Classes: 2 (with_mask, without_mask)
Split: 70% train, 15% validation, 15% test
Format: Images (PNG/JPG) with XML annotations

DATA PREPROCESSING
------------------
Image Size: 224x224 pixels
Normalization: ImageNet statistics
Augmentation:
  - Random horizontal flip (50%)
  - Random rotation (±15 degrees)
  - Color jitter (brightness, contrast, saturation, hue)
  - Random affine transformations (translate, scale)

MODEL TRAINING
--------------
Framework: PyTorch
Loss Function: CrossEntropyLoss
Optimizer: Adam (lr=0.001)
Batch Size: 32 (configurable)
Epochs: 20 per model
Device: Auto-detect (CUDA/CPU)
Total Training: 100 epochs (5 models × 20 epochs)

EVALUATION METRICS
------------------
- Accuracy (overall correctness)
- Precision (weighted average)
- Recall (weighted average)
- F1-Score (harmonic mean of precision and recall)
- Confusion Matrix (true/false positives/negatives)
- Classification Report (per-class metrics)

MODEL ARCHITECTURES
-------------------
1. Custom CNN
   - 3 convolutional blocks
   - BatchNorm + ReLU + MaxPool
   - 2 FC layers with dropout (0.5)
   - ~1.2M parameters

2. ResNet18
   - Pre-trained on ImageNet
   - 18 layers with skip connections
   - Modified final FC layer
   - ~11M parameters

3. MobileNetV2
   - Lightweight architecture
   - Depthwise separable convolutions
   - Inverted residual blocks
   - ~3.5M parameters

4. VGG16
   - 16-layer deep architecture
   - Small 3×3 convolution filters
   - Max pooling for downsampling
   - ~138M parameters

5. EfficientNet-B0
   - Compound scaling method
   - Mobile inverted bottleneck
   - Squeeze-and-excitation blocks
   - ~5.3M parameters
